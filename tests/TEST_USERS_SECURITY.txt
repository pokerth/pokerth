TEST USER CREATION - SECURITY NOTES
===================================

IMPORTANT: NEVER commit the AES encryption key into the repository!

SAFE USAGE
==========

1. Set the AES key as an environment variable:
   export POKERTH_AES_KEY="your_key_here"

2. Call the script:
   ./create_test_users.sh localhost pokerth root 100 "$POKERTH_AES_KEY"

3. Or enter the key directly (keeps it out of the shell history):
   read -s POKERTH_AES_KEY
   ./create_test_users.sh localhost pokerth root 100 "$POKERTH_AES_KEY"

PARAMETERS
==========
$1 - DB host (default: localhost)
$2 - DB name (default: pokerth)
$3 - DB user (default: root)
$4 - number of users (default: 100)
$5 - AES encryption key (REQUIRED!)

EXAMPLES
========
# Locally, with 100 test users:
./create_test_users.sh localhost pokerth root 100 "YOUR_KEY"

# Remote server:
./create_test_users.sh pthsrv.pokerth.net pokerth dbuser 100 "YOUR_KEY"

SQL TEMPLATE
============
The file create_test_users.sql contains a template.
Replace 'YOUR_AES_KEY_HERE' with your key before using it!
